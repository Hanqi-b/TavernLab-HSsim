## 最终行为

- 不携带、下载或安装 Codex 程序；只调用用户已有的 CLI。
- 普通大厅不请求 Codex 接口或启动 Codex 子进程；只有选择 Codex 功能后显示连接面板，检查和测试由明确操作触发。
- 默认复用 `CODEX_HOME` 或 `~/.codex` 的 CLI 登录；游戏代理设置仍存放在独立的游戏状态目录中。不会复制认证文件或修改共享配置目录的权限。
- “检查 CLI”先读取已有账号。只有尚未登录时才需要 `codex login`；登录、退出按钮明确说明会影响本机 CLI 账号。
- 显式设置 `TAVERNLAB_CODEX_HOME` 时仍支持独立认证配置。
- 真人对战 AI 的激进策略入口关闭，旧浏览器偏好迁移到 MCTS；引擎策略与旧存档的兼容行为保留。
- 非真人参战入口及对局标题统一为“观战模式 / …”。
- 新建 GUI 竞技场默认 2016 历史版（12 胜/3 负）；用户仍可选择自选版，已有自选版存档保持原格式。
