# 通灵学园首发版实现与验证

实现目标是历史首发版本 **18.0.0.54613** 的 135 张可收集卡，
而非把所有扩展包更新至今天的规则。原始基础 XML 保持不变。
数据来源、校验和及重现提取方法见 [数据说明](scholomance-data.md)。

## 六个步骤的交付

| 步骤 | 扩展位置 | 交付 |
| --- | --- | --- |
| 1. 补齐数据 | `fireplace/card_data.py`、`cards/Scholomance.xml` | 259 条首发实体，135 张可收集卡；游戏数据库和网页目录共用加载器。 |
| 2. 公共规则 | `spellburst.py`、`health_history.py`、`actions.py`、`game.py` | 法术迸发生命周期、跨发现选择续执行、英雄实际生命变化、死亡历史。 |
| 3. 卡牌效果 | `cards/scholomance/{neutral,nature,shadow,arcane}.py` | 全部新增卡牌效果及衍生物，复用现有动作 DSL、附魔、选择与事件系统。 |
| 4. 系统接入 | `transfer_student.py`、`targeting.py`、`controller` 调用链、卡池筛选 | 转校生棋盘形态、双职业卡池、抉择分支目标、条件战吼目标。 |
| 5. 行为验证 | `tests/test_scholomance_*.py`、`test_spellburst.py`、`test_hero_health_history.py` | 单卡行为、关键边界、完整决策接口对局及确定性回放。 |
| 6. 独立检查与交付 | 独立只读检查、全套回归、wheel 验证、逐卡清单 | 发现的问题修复后纳入回归；逐卡清单可重新生成。 |

## 关键规则边界

- 法术迸发记录施法开始前的有效随从及武器；使用手牌中的实际费用。
  法术完整结算且选择完成后，按顺序执行仍然有效的监听者。
  被反制的法术不消耗迸发；本次法术新召唤的随从不参与本次迸发。
- 迸发在返回手牌、洗回牌库或复活时重置；场上精确复制保留当前已用状态。
- 英雄仅损失护甲、满血治疗和其他无生命值变化的操作不增加生命变化计数。
- 死亡历史与当前墓地分离，保留死亡时控制者及亡语状态；亡语洗回牌库的
  随从仍能被维克图斯、克尔苏加德、憎恨之轮、通窍及亡者复生识别。
- 双职业按职业集合匹配；盗贼“其他职业”卡池排除任何包含盗贼的双职业卡。
- 原生抉择通过选项自己的目标条件校验，网页/Agent 使用相同合法操作接口。
- 秘密通道在本回合结束恢复手牌，嵌套时按后进先出恢复；血骨傀儡（Rattlegore / SCH_621）的复生递减独立于外部强化和属性设置。
- 回放签名包含补充 XML；旧代码、旧卡池下的日志不宣称跨版本兼容。

## 可重现检查

在仓库根目录运行：

```sh
PYTHONPATH=tests:. PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 venv/bin/python -m pytest -q --tb=short --show-capture=no
venv/bin/python -m pip wheel . --no-deps --no-build-isolation --wheel-dir /tmp/tavernlab-scholomance-dist
PYTHONPATH=. venv/bin/python reports/scholomance_2026-10-02/generate.py
git diff --check
```

[逐卡清单](../reports/scholomance_2026-10-02/card_coverage.csv) 将每张卡关联到
实现文件及行为测试引用。测试引用不是对所有可能交互的形式化证明；本次
验证范围也不替代其他历史扩展包的已有质量报告。

## 收藏与现有模式接入补全

| 入口 | 当前行为 |
| --- | --- |
| 卡牌目录 / 收藏 | 共用补充后的卡牌资料，135 张通灵学园卡可查询，组卡按职业集合校验。 |
| 保存卡组对战 | 合法的 30 张通灵学园卡组可保存并从收藏发起真实对局。 |
| 随机对战 | 通灵学园进入随机卡池；双职业卡仅能进入对应职业的卡组。 |
| 竞技场 | 通灵学园作为 3 点大包可选；仅选中该扩展包后，其合法职业卡及中立卡加入选牌池。 |
